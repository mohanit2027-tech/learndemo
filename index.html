Important Git Commands

git init

Creates a new local Git repository.

git add .

Stages changes in the current directory.

git commit

Records staged changes in the repository.

git push

Sends local commits to GitHub.

git pull

Fetches and integrates remote changes.

git clone

Copies an existing repository to your computer.
